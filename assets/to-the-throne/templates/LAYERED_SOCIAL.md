# Layered social-share masters — draft-only

The four social-share master PNGs are preserved byte-for-byte as locked original artwork. Each SVG has separately editable text objects for a concise prayer invitation, verified contextual statement, Scripture when applicable and the weekly archive address.

There is **no automated or approved publishing workflow** from these drafts. The approved social-share images are flattened, so the central text panel is a separately painted replacement region and does NOT faithfully replicate every texture, original decorative arrangement or font. The original top/bottom artwork is kept unmodified. A visible DRAFT ribbon is mandatory.

User approval of the editorial wording, sourced maps, Scripture, and a visually faithful editable master is still required before any release. Never substitute a synthetic test for a weekly ministry post. The social-share production master must be tested with a true approved week and not merely with this fixture.

Usage: `python layered_social.py samples/monday-social-layered-test.json --out /tmp/monday-social-DRAFT.svg`.
